## Правило использования

Файлы в `source-snapshots/` перенесены без смыслового редактирования. Они подтверждают происхождение решений на свою дату, но не автоматически описывают текущее состояние продукта.

Упоминания `53/53`, `main@4664018`, незавершённой repository-консолидации и отсутствующих workshop-расчётов исторические: после 13 августа продукт развивался в `feature/checkerboard-manufacturing-v1`. Текущий статус фиксируют root [README](../../README.md) и [CONSOLIDATION_REPORT](../../CONSOLIDATION_REPORT.md).

Цены, размер первой партии, каналы, KPI и другие коммерческие параметры остаются директорской моделью для проверки, а не доказанными продажами или публичной офертой. Написание `DREVOCODE` в старом источнике сохранено для provenance; каноническое имя — `DREVOCOD`.
