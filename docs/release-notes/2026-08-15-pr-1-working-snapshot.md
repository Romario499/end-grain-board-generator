# PR №1 — рабочий snapshot описания

Источник: локальный `.superpowers/pr-body-drevocod.md` перед финализацией 2026-08-16. Сохранён как исторический snapshot; число тестов и границы продукта отражают состояние на момент написания.

## Что изменено

- проект объединён под брендом DREVOCOD и продуктом End Grain Studio;
- добавлена schema V2 и безопасная миграция сохранённых V1-проектов;
- добавлен воспроизводимый checkerboard generator с seed;
- добавлен workshop recipe: kerf, припуски, первая панель, срезы, объём и отходы;
- условные овалы заменены детерминированной анатомией end grain с кольцами, порами и лучами;
- палитра привязана к American hard maple, American black walnut и American black cherry;
- добавлены актуальные US 8/4 stock offers и рыночные цены-ориентиры;
- обновлены конкурсный интерфейс, README и печатная инструкция.

## Зачем

Конкурс требует не только рисовать узор, но и объяснять, как изготовить реальную торцевую доску. Изменения связывают визуальный редактор с воспроизводимым шаблоном, параметрами мастерской и проверяемым материалом.

## Влияние

Пользователь может создать или отредактировать узор, задать размеры и пропил, увидеть технологическую оценку, сохранить проект, экспортировать PNG и распечатать последовательность изготовления.

## Проверка на момент snapshot

- `npm run check`;
- 103/103 автоматических теста;
- синтаксис всех JS-файлов;
- локальная страница и новые модули отвечают HTTP 200.

## Границы на момент snapshot

Расчёт raw stock, фактическая себестоимость, оборудование, фотографический AI-preview и физическая верификация изделия оставались следующими этапами. UI не выдавал их за готовые функции.
