# Спецификация P0

Источник истины — версионированный документ проекта: метаданные, доска, палитра и массив ячеек. Сетка 1–64 по каждой оси. Размеры: 50–3000 мм для длины/ширины и 5–300 мм для толщины. Сохранение локальное. PNG имеет длинную сторону 2400 px. Любые производственные расчёты, PDF и 3D находятся вне P0.
