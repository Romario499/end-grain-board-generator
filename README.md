# DREVOCOD — End Grain Studio

**Functional geometry. Built in end grain.**

Конкурсный browser-first генератор торцевых разделочных досок и технологическое ядро бренда DREVOCOD. Инструмент связывает проектирование узора с чистовыми размерами, пропилом, припусками, расходом и последовательностью изготовления.

## Что уже работает

- ручной редактор узора с покраской, выделением, поворотом и отражением;
- American hard maple, American black walnut и American black cherry;
- детерминированные реалистичные end-grain текстуры: нерегулярные кольца, поры и сердцевинные лучи;
- воспроизводимый шахматный шаблон с seed и режимом «Удивить меня»;
- настройка длины, ширины, толщины и сетки;
- расчёт толщины среза, первой панели, количества поперечных пилов, подготовленного объёма и отходов;
- пошаговый рецепт переклейки;
- локальное сохранение и открытие проектов schema V2 с миграцией V1;
- PNG через тот же Canvas-рендер, что используется в редакторе;
- печатная версия инструкции;
- защита несохранённой работы.

Технологический расчёт имеет статус **оценки**, пока пользователь не задал реальные складские заготовки, ограничения оборудования и цены. Проект не заявляет неподтверждённые сертификаты, место производства или полную физическую верификацию.

## Запуск

Требуется Node.js 20+.

```bash
npm run serve
```

Открыть: `http://127.0.0.1:8080`.

## Проверка

```bash
npm test
npm run check
```

Внешние runtime-зависимости не используются.

- **DREVOCOD** — бренд и единый бизнес-контур;

- **CUBE 18** — первый продукт-локомотив и следующий параметрический пресет;
