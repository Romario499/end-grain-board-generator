# Торец

Локальный browser-first редактор узоров торцевых разделочных досок.

## P0

- сеточный редактор узора;
- минимум три материала;
- поворот и отражение элементов;
- размеры доски;
- локальное сохранение и открытие;
- экспорт PNG.

## Команды

- `npm test` — автоматические тесты.
- `npm run check` — тесты и проверка синтаксиса.
- `npm run serve` — локальный сервер на `http://127.0.0.1:8080`.

Внешние зависимости не используются.
