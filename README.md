# DREVOCOD — End Grain Studio

**Functional geometry. Built in end grain.**

Browser-first генератор торцевых разделочных досок и технологическое ядро бренда DREVOCOD. Инструмент связывает проектирование узора с чистовыми размерами, пропилом, припусками, расходом и последовательностью изготовления.

## Что уже работает

- ручной редактор узора с покраской, выделением, поворотом и отражением;
- American hard maple, American black walnut и American black cherry;
- детерминированные реалистичные end-grain текстуры: нерегулярные кольца, поры и сердцевинные лучи;
- воспроизводимый шахматный шаблон с seed и режимом «Удивить меня»;
- параметрический CUBE 18 с тремя ромбическими гранями 60°/120°;
- настройка длины, ширины, толщины и сетки;
- расчёт толщины среза, первой панели, количества поперечных пилов, подготовленного объёма и отходов;
- производственная оценка CUBE 18: полосы, детали, резы 30°, kerf, board feet и себестоимость по ставкам мастерской;
- пошаговые рецепты checkerboard и CUBE 18;
- локальное сохранение и открытие проектов schema V2 с миграцией V1;
- PNG через тот же Canvas-рендер, что используется в редакторе;
- печатная версия инструкции;
- защита несохранённой работы.

## Граница достоверности

Технологический расчёт имеет статус **оценки**. Для CUBE 18 он начинается с подготовленных полос и не включает автоматически сырой складской раскрой, труд, доставку, налог или амортизацию. До физической контрольной сборки результат не считается подтверждённой техкартой изделия. Проект не заявляет неподтверждённые сертификаты или производственные возможности.

## Запуск

Требуется Node.js 20+.

```bash
npm run serve
```

Открыть: `http://127.0.0.1:8080`.

## Проверка

```bash
npm test
npm run check
```

Внешние runtime-зависимости не используются.

Тестовый набор содержит 123 объявленных сценария в 33 файлах. `npm run check` запускает весь набор и синтаксическую проверку JavaScript.

## Архитектура продукта

- **первая проверка** — собственная мастерская и физический образец.
