# Wood texture assets

Для каждой породы сохранены два варианта одного визуального источника:

- `*.png` — master-asset 1254 × 1254 для архива и последующей обработки;
- `*.jpg` — оптимизированный runtime-asset 768 × 768, который загружает End Grain Studio.

Приложение намеренно использует JPG: три master PNG занимают около 9.3 MB, а три runtime JPG — около 0.5 MB. Замена runtime-файлов требует визуальной проверки Canvas-превью и PNG-экспорта.
